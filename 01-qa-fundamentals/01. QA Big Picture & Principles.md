# 🌐 01. QA Big Picture & Principles

> **Big Picture ≠ Detailed Knowledge**  
> *This file explains the WHY of QA — ทำไมต้องมี QA และ QA มีบทบาทอะไรใน Software Development*

---

## 🎯 QA คืออะไร?

**Quality Assurance (QA)** คือกระบวนการและแนวทางในการสร้างความมั่นใจว่า Software มีคุณภาพ ตรงตามความต้องการของผู้ใช้และธุรกิจ

QA ไม่ได้หมายถึงแค่การ Test หรือการหา Bug เท่านั้น แต่รวมถึงการป้องกันปัญหา การปรับปรุงกระบวนการ และการลดความเสี่ยงของระบบ

### Testing เป็นส่วนหนึ่งของ QA

```text
           |
 ┌────────────────────┐
 | Requirement Review |

```

---
### 🎯 เป้าหมายหลักของ QA

1.  **Preventing Defects** - ป้องกันปัญหาตั้งแต่ต้นทาง เป้าหมายคือไม่ให้ปัญหาเกิดขึ้นตั้งแต่แรก
	- Requirement Review
	- Design Review
	- การสื่อสารระหว่างทีม

2. **Reducing Risk** - ลดความเสี่ยงของระบบก่อน Release QA ต้องวิเคราะห์ว่า
	- จุดไหนมีโอกาสเกิดปัญหา
	- จุดไหนส่งผลกระทบต่อผู้ใช้หรือธุรกิจมากที่สุด

3. **Finding Defects** - ค้นหาข้อบกพร่องที่ยังมีอยู่ในระบบเพื่อให้ทีมสามารถแก้ไขปัญหาก่อนส่งมอบให้ผู้ใช้

4. **Providing Information** - ให้ข้อมูลเกี่ยวกับคุณภาพของระบบ เช่น 
	- Test Result
	- Defect Status
	- Remaining Risk
   เพื่อช่วยให้ทีมและ Stakeholder ตัดสินใจได้ดีขึ้น
	
5. **Gaining Confidence** - สร้างความมั่นใจว่า Software มีคุณภาพและพร้อมใช้งาน

# 📚 ทำไมต้องเรียนหัวข้อต่อไป?

## 1️⃣ SDLC & STLC Framework

**ทำไมต้องเรียน?**

- เข้าใจกระบวนการพัฒนา Software
- รู้ว่า QA มีบทบาทในแต่ละช่วงของ Development
- เข้าใจ Workflow การทำงานจริง

---

## 2️⃣ Quality & Risk Thinking

**ทำไมต้องเรียน?**

- เข้าใจมุมมองเรื่อง Quality
- เรียนรู้การคิดแบบ Risk-Based Testing
- รู้ว่าควรเลือก Test อะไรก่อนหลัง

---

## 3️⃣ Verification vs Validation

**ทำไมต้องเรียน?**

- เข้าใจความแตกต่างระหว่าง
    - Building the product right
    - Building the right product
- เข้าใจว่าการตรวจสอบคุณภาพไม่ได้มีแค่การ Test

---

## 4️⃣ Software Testing Principles

**ทำไมต้องเรียน?**

- เข้าใจหลักการคิดพื้นฐานของ Testing
- เข้าใจข้อจำกัดของการ Test
- เรียนรู้ว่าทำไมเราไม่สามารถ Test ทุกอย่างได้ 100%

---

## 5️⃣ Testing Types Overview

**ทำไมต้องเรียน?**

- เข้าใจประเภทของ Testing
- เลือกวิธี Test ให้เหมาะกับสถานการณ์
- เข้าใจความแตกต่างระหว่าง Functional และ Non-Functional Testing

---

## 6️⃣ Test Design Techniques

**ทำไมต้องเรียน?**

- ออกแบบ Test Case อย่างเป็นระบบ
- เพิ่ม Coverage ในการทดสอบ
- ค้นหา Defect ได้มีประสิทธิภาพมากขึ้น
