# 🔗 06. Requirements Traceability Matrix (RTM)

**หมวด:** QA Process  
**Objective:** สร้างตารางความเชื่อมโยงระหว่าง Requirement, Acceptance Criteria และ Test Case เพื่อรับประกันความครอบคลุมและช่วยในการวิเคราะห์ผลกระทบ

> "RTM คือใบเสร็จยืนยันว่า ทุกความต้องการของลูกค้า มีการทดสอบรองรับเสมอ"

---

## 🎯 Purpose

สร้างตารางความเชื่อมโยงระหว่าง Requirement, Acceptance Criteria และ Test Case  
เพื่อรับประกันความครอบคลุม (Test Coverage) และช่วยในการวิเคราะห์ผลกระทบ (Impact Analysis)

---

## 🧠 RTM คืออะไร?
**RTM (Requirement Traceability Matrix)**  
คือตารางที่ใช้ **Trace ความสัมพันธ์** ระหว่าง
- Requirement
- Test Scenario / Test Case
- (Optional) Defect


---

## 🔗 RTM ใช้ตอนไหน?
- หลัง Requirement ชัดเจน
- หลังเขียน Test Case เสร็จ
- ก่อนเริ่ม Test Execution / Release

---

## 🏗️ 1. โครงสร้างของ RTM (Mapping Structure)


RTM ที่ดีควรเชื่อมโยงข้อมูลแบบ 1-to-Many ได้ โดยไล่เรียงดังนี้: 
`Business Requirement` ⮕ `User Story / AC` ⮕ `Test Case` ⮕ `Test Result / Defect`

## 🎯 3. ประโยชน์ของ RTM (Why we need it?)

1. **Ensuring 100% Coverage:** เช็คดูว่ามี Requirement ข้อไหนที่ "ไม่มี" Test Case ผูกอยู่บ้าง (ถ้ามีช่องว่าง แสดงว่าเราลืมเทส)

2. **Impact Analysis:** ถ้าลูกค้าขอแก้ REQ-01 เราจะรู้ทันทีว่าต้องไปอัปเดต TC-TRF-001 และ 002
    
3. **Reporting:** สรุปภาพรวมความคืบหน้าได้ง่าย (เช่น Requirement นี้ผ่านแล้ว 80%)
    
4. **Audit Trail:** ใช้เป็นหลักฐานยืนยันความถูกต้องในระดับคุณภาพ (Quality Audit)
    

---

## 🔍 4. วิธีการทำ RTM ให้มีประสิทธิภาพ

- **Bidirectional Traceability:** ต้องเช็คได้ทั้ง "หน้าไปหลัง" (REQ -> TC) และ "หลังมาหน้า" (TC -> REQ) เพื่อดูว่ามี Test Case ไหนที่เขียนเกินมาโดยไม่มี Requirement สั่งหรือไม่
    
- **Keep it Simple:** ไม่จำเป็นต้องใส่ Step การเทสลงไปใน RTM ให้ใส่แค่ ID เพื่ออ้างอิง
    
- **Update Regularly:** RTM ต้องถูกอัปเดตทุกครั้งที่ Requirement เปลี่ยน หรือเมื่อออกแบบ Test Case ใหม่เสร็จ
    

---

## ✅ Checklist สำหรับ RTM

- [ ] Requirement ทุกข้อมี Test Case ผูกอยู่แล้วอย่างน้อย 1 เคส
    
- [ ] Test Case ทุกเคสมี Requirement อ้างอิง (ไม่มีเคสที่เขียนขึ้นมาลอยๆ)
    
- [ ] ระบุสถานะ (Pass/Fail) ล่าสุด เพื่อให้เห็นภาพรวมคุณภาพ
    
- [ ] มีการเชื่อมโยงถึง Defect/Bug ID (ถ้ามี)
